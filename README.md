# Estud_v.2

Estud_v.2 is a small web app for students to exchange study resources from older batches to newly joined fresh students.

## Features

- Older-batch students can share resources with title, subject, description, optional link, and their name.
- Fresh students can view available resources.
- Fresh students can claim a resource by adding their name and contact.
- Data is stored locally in the browser using `localStorage`.

## Run locally

1. Clone the repository.
2. Open `/home/runner/work/Estud_v.2/Estud_v.2/index.html` in a browser.

No backend is required for this version.
